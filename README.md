## კონკურსის მიმოხილვა
IEEE-CIS Fraud Detection კონკურსის მიზანია საბანკო ტრანზაქციებზე თაღლითობის პროგრონზირება სხვადასხვა ფიჩერებზე, მახასიათებლებზე დაყრდნობით, კერძოდ, მოწყობილობის ტიპის, ბარათის ინფორმაციის, თანხის და სხვა. მონაცემები შედეგბა ორი ნაწილისგან: Transaction ცხრილი და Identity ცხრილი. პირველ ცხრილშ წერია ტრანზაქციის დეტალები, ხოლო მეორეში მომხმარებლის მოწყობილობის ინფორმაცია.  ამ ამოცანას ვაფასებთ area under the ROC curve - მეტრიკის გამოყენებით. 

### მიდგომა ამ ამოცანის გადასაჭრელად
ეტაპობრივად მიდგომას ავირჩევ. გამოვცდი რამდნეიმე კლასიფიკაციისთვის შეასაფერის მოდელებს, Logistic Regression-იდან დაწყებული უფრო რთული და კომპლექსური მოდელებისკენ გადავალ. ფიჩერების გადარჩევასაც გავაკეთებ ეტაპობრივად და მერე საბოლოო შედეგის მიხედვით ვნახავ რომელმა გადარჩვეებმა გაამართლა ყველაზე კარგად და საუკეთსოს ამოვირჩევ. ანუ მოდელის შედეგებს შევადარებ ROC-AUC მეტრიკით და.

## AdaBoost
აქაც იგივე 
მარტივი ახსნა:
AdaBoost თანმიმდევრულად ამატებს სუსტ მოდელებს — თითოეული ცდილობს წინა მოდელის შეცდომები გაასწოროს. Learning Rate კი აკონტროლებს რამდენად ენდობა თითოეულ ახალ მოდელს.
ანალოგია:
წარმოიდგინე სტუდენტი რომელიც გამოცდისთვის ემზადება:

learning_rate=1.0 → ყოველ ახალ მასალას სრულად ენდობა — სწრაფად ისწავლის მაგრამ შეიძლება ზედმეტად დაეყრდნოს ერთ წყაროს
learning_rate=0.1 → ყოველ ახალ მასალას ნელ-ნელა ითვისებს — უფრო სტაბილური სწავლა
learning_rate=0.01 → ძალიან ნელა ისწავლის — შეიძლება საკმარისი არ იყოს
learning_rate დაბალია → მეტი n_estimators სჭირდება
learning_rate მაღალია → ნაკლები n_estimators სჭირდება.
learning_rate=0.1 ავირჩიეთ რადგან დაბალი 
learning_rate უფრო სტაბილურ სწავლას იძლევა 
და Overfitting-ის რისკს ამცირებს. შესაბამისად 
n_estimators=100 გამოვიყენეთ რომ მოდელს 
საკმარისი რაოდენობის სუსტი მოდელი ჰქონდეს.
Random Forest → class_weight='balanced' ხელით უნდა დავამატოთ
AdaBoost → ავტომატურად ზრდის გამოტოვებული შემთხვევების წონას 
AdaBoost-ი განსაკუთრებით კარგად უმკლავდება 
დაუბალანსებელ dataset-ს — თითოეულ იტერაციაში 
გამოტოვებულ Fraud შემთხვევებს მეტ წონას 
ანიჭებს და მომდევნო მოდელი მათზე უფრო 
მეტად ფოკუსირდება.
