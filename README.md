## კონკურსის მიმოხილვა
IEEE-CIS Fraud Detection კონკურსის მიზანია საბანკო ტრანზაქციებზე თაღლითობის პროგრონზირება სხვადასხვა ფიჩერებზე, მახასიათებლებზე დაყრდნობით, კერძოდ, მოწყობილობის ტიპის, ბარათის ინფორმაციის, თანხის და სხვა. მონაცემები შედეგბა ორი ნაწილისგან: Transaction ცხრილი და Identity ცხრილი. პირველ ცხრილშ წერია ტრანზაქციის დეტალები, ხოლო მეორეში მომხმარებლის მოწყობილობის ინფორმაცია.  ამ ამოცანას ვაფასებთ area under the ROC curve - მეტრიკის გამოყენებით. 

### მიდგომა ამ ამოცანის გადასაჭრელად
ეტაპობრივად მიდგომას ავირჩევ. გამოვცდი რამდნეიმე კლასიფიკაციისთვის შეასაფერის მოდელებს, Logistic Regression-იდან დაწყებული უფრო რთული და კომპლექსური მოდელებისკენ გადავალ. ფიჩერების გადარჩევასაც გავაკეთებ ეტაპობრივად და მერე საბოლოო შედეგის მიხედვით ვნახავ რომელმა გადარჩვეებმა გაამართლა ყველაზე კარგად და საუკეთსოს ამოვირჩევ. ანუ მოდელის შედეგებს შევადარებ ROC-AUC მეტრიკით და.

აქც ჯერ  TransactionAmt log ად გარდავქმნი რო ძაან დიდი რიცხვებთან არ მქოდნეს, შეხება. ანუ "ნორმალიზაცია" რო გავაკეთო. საათის და კვირის დღეებზე გავამახვილოთ ყურადგღება რადგან ღამით ხდებ აყველაზე მეტი თაღლითობა.
